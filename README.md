# 📊 Magalu HQ — Dashboard de Diretoria FY26

Dashboard interativo de vendas iPhone por Diretoria — MAGALU HQ.

## Como usar
1. Baixe `magalu_dashboard.html`
2. Abra em qualquer browser
3. Navegue pelas 5 abas (Magalu Brasil + 4 Diretorias)
4. Selecione o mês: Abril / Maio / Junho

## Estrutura
- 5 abas: MAGALU BRASIL · MG/CO · N/NE · SP/RJ · SUL · VIRTUAL
- 3 meses: Abril (W1-W5) · Maio (W6-W9) · Junho (W10-W13)
- Filtro: PARTNER=MAGALU HQ · SubLOB≠Total
- Gráficos: Vendas por Território + Mix de Modelos (%) + Top 15 Lojas
